# شفرة النظام – The Order Code

لعبة تعليمية تفاعلية لاجتماع الإعدادي، بعنوان «إلهنا إله نظام».
خمس مراحل متصلة في شاشة واحدة، بملف HTML واحد بدون أي مكتبات خارجية، وتعمل بدون إنترنت.

## التشغيل
- محلياً: افتح `index.html` في Chrome.
- على الإنترنت (GitHub Pages): Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
  الرابط يظهر بعد دقيقة تقريباً بالشكل: `https://USERNAME.github.io/REPO-NAME/`

## المراحل
1. سر الخليقة: ترتيب أيام الخليقة (تك ١–٢)
2. بيت الله: توصيل الأدوار بوظائفها في الكنيسة
3. سر الوقت: توزيع ٢٤ ساعة بتوازن
4. من الفوضى للسلام: مواقف وقرارات
5. الشفرة الأخيرة: ١ كو ١٤: ٣٣ و١٤: ٤٠

## لوحة المُيسّر
أيقونة ⚙️ أعلى الشاشة: إظهار الإجابات، تعديل النقاط، إكمال أو إعادة المرحلة، إعادة اللعبة.

## التخصيص
كل المحتوى داخل `index.html` في قسم `content` (المصفوفات `C1` و`M2` و`A3` و`SC`).
